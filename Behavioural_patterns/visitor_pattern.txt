1️⃣ What is Visitor Pattern?

Simple definition:
Visitor Pattern lets you add new operations to existing object structures without modifying their classes.

👉 You move the operation logic outside the objects into a separate Visitor class.

2️⃣ Why do we need Visitor Pattern?

Imagine this problem 👇

You have different objects:

Circle

Rectangle

Triangle

Now you want to:

Calculate area

Calculate perimeter

Export to JSON

Export to XML

❌ If you add these methods inside every shape class → class explosion
❌ Modifying existing classes again and again → breaks Open/Closed Principle

✅ Visitor Pattern solves this.

3️⃣ Real-world analogy 🧠
Doctor visiting patients 🩺

Patients: Child, Adult, Senior

Doctor (Visitor) performs:

Check BP

Check Sugar

Check Heart

Patients accept the doctor, and the doctor decides what to do.

Patient.accept(Doctor)
Doctor.visit(PatientType)

5️⃣ Java Implementation (Step by Step)
Step 1: Element Interface
public interface Shape {
    void accept(ShapeVisitor visitor);
}

Step 2: Concrete Elements
Circle
public class Circle implements Shape {
    int radius;

    public Circle(int radius) {
        this.radius = radius;
    }

    @Override
    public void accept(ShapeVisitor visitor) {
        visitor.visit(this);
    }
}

Rectangle
public class Rectangle implements Shape {
    int length;
    int breadth;

    public Rectangle(int length, int breadth) {
        this.length = length;
        this.breadth = breadth;
    }

    @Override
    public void accept(ShapeVisitor visitor) {
        visitor.visit(this);
    }
}

Step 3: Visitor Interface
public interface ShapeVisitor {
    void visit(Circle circle);
    void visit(Rectangle rectangle);
}

Step 4: Concrete Visitor (Operation Logic)
Area Calculator Visitor
public class AreaVisitor implements ShapeVisitor {

    @Override
    public void visit(Circle circle) {
        double area = Math.PI * circle.radius * circle.radius;
        System.out.println("Circle Area: " + area);
    }

    @Override
    public void visit(Rectangle rectangle) {
        int area = rectangle.length * rectangle.breadth;
        System.out.println("Rectangle Area: " + area);
    }
}

Step 5: Client Code
public class VisitorDemo {
    public static void main(String[] args) {

        Shape circle = new Circle(5);
        Shape rectangle = new Rectangle(4, 6);

        ShapeVisitor areaVisitor = new AreaVisitor();

        circle.accept(areaVisitor);
        rectangle.accept(areaVisitor);
    }
}

Output
Circle Area: 78.53981633974483
Rectangle Area: 24

6️⃣ Key Concept: Double Dispatch ⚡

Visitor uses double dispatch:

1️⃣ Object type decides which accept() is called
2️⃣ Visitor decides which visit() method to execute

👉 This avoids instanceof checks ❌

7️⃣ Advantages 🚀

✅ Add new operations easily
✅ Open/Closed Principle
✅ Cleaner separation of logic
✅ No if-else or instanceof

8️⃣ Disadvantages ⚠️

❌ Adding a new element requires changing all visitors
❌ Can be complex for beginners
❌ Breaks encapsulation slightly
